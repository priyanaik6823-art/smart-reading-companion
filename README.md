# smart-reading-companion
A full-stack web application designed to enhance the reading experience by helping users upload, manage, and track their books while providing an interactive and user-friendly interface.

## 🚀 Features

- User Authentication (Register & Login)
- Secure JWT-based Authorization
- Upload and Manage Books
- Book Details and Descriptions
- Reading Progress Tracking
- Recently Read Books Dashboard
- Responsive Design for Desktop and Mobile
- Modern UI with Tailwind CSS
- Smooth Animations using Framer Motion

## 🛠️ Technologies Used

### Frontend
- React.js
- React Router
- Tailwind CSS
- Framer Motion
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt.js
